## Disputes and decisions

1. **Group 4: a bank "-0" is zero, not an error** (`amount < 0m`); every zero leaves the mapping without a sign bit. No test pins "-0"; D2's "negative" read as below zero.
2. **Group 5: the repeated-key check runs before the cap check,** so a 20th page repeating an earlier key fails with the repeated-key message (the more specific one).
3. **Group 7: what the log line's error code says.** No `error` value (`none`): an empty body, JSON `null`, HTML, plain text, a JSON array or string at the top level, a missing, null or blank `error`. A value of another shape (`unrecognised`): a text that is not code-shaped, and a non-string `error` (number, object, array, boolean), since a value is there.

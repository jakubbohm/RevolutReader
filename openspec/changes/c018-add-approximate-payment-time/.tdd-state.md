## What the code holds now (after chapter B)

  - `FirstSeenRule` (pure):
    - `ReadAt`: UTC, whole seconds;
    - `Sightings`: the transactions dated `readAt`'s UTC date, each with a reference, each reference once (ordinal), at `readAt`;
    - `Shown`: the moment only when its UTC date is the transaction's date.

  - `FirstSeenTimes`, scoped (`TransactionsRegistration`): it reads every reference of the read, records only the sightings with no moment yet, and answers the kept moments overlaid with `Record`'s answer.

  - `RecordFirstSeenHandler(bank, FirstSeenTimes, time, logger)`, scoped (`AddAccountCheck`):
    - It reads the transactions from the UTC day before the clock's today, as the present user.

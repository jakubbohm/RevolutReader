**Why:** the only Atlassian site connected to Claude is the employer's (`cemexpmo`), unrelated to this personal project. Looking there for a RevolutReader project wasted a step and touched the employer's tools.

**How to apply:** when the user says ticket, Jira ticket or issue, create or update a GitHub issue in this repository (format of the existing ones: Goal, Background with links, proposal, what to decide, where it lands in the roadmap; the attribution footer). Never call the Atlassian tools for this project. Related: [[az-always-explicit-subscription]] (same rule for the employer's Azure).
